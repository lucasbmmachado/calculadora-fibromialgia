# Calculadora clínica de fibromialgia — critérios ACR 2016

Protótipo educacional em português do Brasil. Aplicação estática, sem backend, banco de dados ou envio de respostas.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `calculadora-fibromialgia`).
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`; salve.
6. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## O que a ferramenta calcula

- WPI: 19 áreas de dor nos últimos sete dias.
- SSS: gravidade de fadiga, sono não reparador e sintomas cognitivos, mais três sintomas adicionais.
- Duração dos sintomas por pelo menos três meses.
- Distribuição da dor em pelo menos quatro de cinco regiões.

## Limitações importantes

Esta ferramenta apoia a verificação dos critérios classificatórios ACR 2016, mas não substitui avaliação clínica, exame físico ou diagnóstico diferencial. Revise o conteúdo e teste a ferramenta antes de qualquer uso clínico institucional. Não inserir dados identificáveis de pacientes.

## Referência

Wolfe F, Clauw DJ, Fitzcharles MA, et al. 2016 Revisions to the 2010/2011 fibromyalgia diagnostic criteria. *Seminars in Arthritis and Rheumatism*. 2016;46(3):319–329. https://doi.org/10.1016/j.semarthrit.2016.08.012
